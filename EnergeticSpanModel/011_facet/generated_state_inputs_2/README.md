# Generated Mn3O4 State Inputs

This directory was generated by:

```bash
python 011_facet/generate_mn3o4_state_inputs.py
```

The generated folders follow this state notation:

```text
S{o}{c}{x}/variant_XX
```

- `o`: olation count, `0..3`
- `c`: condensation count, `0..2`, with `c <= o`
- `x`: oxidation count, `0..2`

Each state has three variants:

```text
S000/variant_01
S000/variant_02
S000/variant_03
...
S322/variant_01
S322/variant_02
S322/variant_03
```

Each variant contains the required VASP input files:

```text
INCAR
POSCAR
POTCAR
KPOINTS
```

## Source Structures

- Starting slab: `011_facet/12layer_magmom/0/POSCAR`
- Final layer reference: `011_facet/12layer_3rd_magmom/oxooxooxiolaoxi/POSCAR`

The generator matches the starting slab to the final reference by coordinates and reuses the unmatched final-layer Mn/O positions as adsorption-site templates.

## Stoichiometry Used

The generated atom counts follow:

```text
Mn = Mn_slab + o
O  = O_slab + 2*o - c
H  = H_slab + max(0, 2*o - 2*c - x) - max(0, x - (2*o - 2*c))
```

Examples:

```text
S100 = +Mn(OH)2
S110 = +MnO
S322 = +Mn3O4
```

## MAGMOM Rule

The `INCAR` files are rewritten after POSCAR generation.

- Slab Mn3+ positions: `+3.8 / -3.8`
- Slab Mn2+ positions: `4.4`
- Adsorbed Mn and all non-Mn atoms: `0.0`

The number of MAGMOM entries is validated against the POSCAR atom count.

## Important

These structures are starting guesses. Inspect the POSCAR files visually before submitting expensive DFT jobs, especially early olation states where terminal OH-like O/H positions are generated geometrically rather than copied from an optimized structure.
