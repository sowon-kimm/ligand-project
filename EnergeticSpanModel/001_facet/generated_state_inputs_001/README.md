# Generated Mn3O4 State Inputs for 001 Facet

This directory was generated by:

```bash
python 001_facet/generate_mn3o4_state_inputs.py
```

State notation:

```text
S{o}{c}{x}/variant_XX
```

- `o`: olation count, `0..3`
- `c`: condensation count, `0..2`, with `c <= o`
- `x`: oxidation count, `0..2`

Each state has three variants, so the output contains:

```text
27 states x 3 variants = 81 input folders
```

Each variant contains:

```text
INCAR
POSCAR
POTCAR
KPOINTS
```

## Source Structures

- Starting slab: `001_facet/magmom_test/initial/POSCAR`
- Final layer reference: `001_facet/vac30_layer12_magmom/olaoxioxooxioxo/POSCAR`

The generator matches the starting slab to the final reference by coordinates and reuses the unmatched final-layer Mn/O positions as adsorption-site templates.

## MAGMOM Rule

The generated `INCAR` files are rewritten after POSCAR generation.

- Base 001 slab Mn pattern: `4*+3.8, 4*-3.8, 4*4.4`
- Adsorbed Mn and all non-Mn atoms: `0.0`

The number of MAGMOM entries was validated against the POSCAR atom count.

## Important

These structures are DFT starting guesses. Inspect representative POSCAR files visually before submitting expensive jobs, especially states with terminal OH groups generated geometrically.
